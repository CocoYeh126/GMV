01操作說明

1

更新資料集

將最新的每日 GMV 資料（含日期、Biz Type、Day Type、ttl_gmv 欄位）存成 data.csv，覆蓋專案資料夾裡的舊檔。

2

執行模型

在專案資料夾的終端機執行 python3 analysis.py（Windows 為 py analysis.py）。終端機會顯示「本次執行：○○（資料截止 ○○）」，請確認資料截止日正確。

3

匯入 Google Sheet

把 output 資料夾裡的四份 CSV 匯入同名分頁：monthly_predictions、daily_forecast、mtd_summary、factor_summary。每個分頁都用「檔案 → 匯入 → 上傳」，匯入位置選「取代目前的工作表」。

4

重新整理儀表板

儀表板只在開啟時讀一次資料，匯入後要重新整理頁面。頁面頂端的「資料更新至 ○○」應該和終端機顯示的資料截止日相同。

02功能介紹

全月預估（日均）

模型對該月份全月 GMV 的預估，換算成每天平均的金額。

MTD 實際（日均）

當月 1 日到資料截止日的實際 GMV，換算成每天平均的金額。

校正係數與校正後全月預估（日均）

校正係數 = MTD 實際 ÷ 同期間的預估，大於 1 代表目前比預估快。校正後全月預估 = MTD 實際 + 剩餘天數預估 × 校正係數。

以折線圖比較每個月的實際與預估，用來看長期趨勢和預估準不準。

每日實際 vs 預估

以圖表比較選定月份每一天的實際與預估，用來看哪幾天和預估差最多。

每日明細

以表格列出選定月份每一天的預估與實際 GMV。

04模型邏輯

步驟 1　定義候選因子

因子定義
上個月 GMV目標月前一個月（t−1）的 GMV
近三個月 GMV 平均t−1、t−2、t−3 三個月 GMV 的平均
去年同期 GMV目標月去年同月（t−12）的 GMV
MoM 月成長率(t−1 − t−2) ÷ t−2
YoY 年成長率(t−1 − t−13) ÷ t−13，也就是上個月相對於去年同月的成長率

步驟 2　相關係數篩選

以 2025-01 起的所有完整月份，計算各 Biz Type 中的每個候選因子與實際 GMV 的相關係數，最後於各 Biz Type 中排除相關係數 |r| < 0.44 的因子，其餘作為訓練因子。

r = Σ(x − x̄)(y − ȳ) ÷ √[ Σ(x − x̄)² × Σ(y − ȳ)² ]

x 為因子值、y 為實際 GMV，x̄、ȳ 為各自的平均值；r 介於 −1 到 1，越接近 ±1 關聯越強。

以 2026-10 的預估為例，各 Biz Type 經過篩選後留下的因子如下：

Biz Type篩選後留下的因子
C2CYoY 年成長率
Mall上個月 GMV、近三個月 GMV 平均
B2C上個月 GMV、近三個月 GMV 平均、MoM 月成長率

步驟 3　選定因子組合

將篩選後的因子組成多種組合，以 2025-01 至最近一個完整月份的歷史資料逐月進行模擬預測，並計算各組合的平均誤差率。最後以誤差率最低的組合，作為各 Biz Type 的預測因子。

用來預測的月份 被預測的月份
  • 依照相關係數篩選後的結果，列出各 Biz Type 中所有可能的因子組合，每一個組合都將進行模擬預測。
  • 針對各 Biz Type 中每種組合，以第 1～6 月資料預測第 7 月、第 1～7 月資料預測第 8 月⋯依此類推至最後一個完整月份；每次預測都會產生一個誤差值，將同一組合的所有誤差值取平均。
  • 比較各組合之平均誤差，取誤差最低之組合，作為該 Biz Type 之預測因子。

因子組合在每次產出正式預估時重新挑選，所以不同月份可能採用不同的因子。2026-10 正式預估選定的預測因子如下，其他月份以儀表板的因子標籤為準。

Biz Type2026-10 選定的預測因子
C2CYoY 年成長率
Mall上個月 GMV + 近三個月 GMV 平均
B2C上個月 GMV

步驟 4　正式預估（每月 1 號）

針對各 Biz Type，用最終選定的因子組合，以全部月份計算出一條迴歸公式；每次預測時，代入以目標月為基準計算的因子數值，計算出下個月的 GMV 預測值。

全月預估 = 截距 + Σ（係數 × 因子值）

步驟 5　每日預估

將每一天歸類到對應的 Day Type，再依照最近 3 個完整月份各 Day Type 的業績占比，把全月預估分配到每一天。

  1. 取目標月之前最近 3 個完整月份，算出各 Day Type 占當月業績的百分比。
  2. 百分比 ÷ 該月這個 Day Type 的天數，換算成「每一天」的占比。
  3. 3 個月的每天占比取平均（某 Day Type 某月沒出現時，只平均有出現的月份）。
  4. 把目標月每一天標上 Day Type，填入對應的每天占比。
  5. 加總所有天的占比，再把每天的占比 ÷ 加總，讓全月合計為 100%。
  6. 全月預估 × 每天調整後占比 = 每日預估。

05相關指標說明

模型篩選與儀表板上出現的指標。

日均 GMV

Average daily GMV

儀表板上的金額都以日均顯示，方便比較天數不同的月份，也方便比較 MTD 與全月。

日均 GMV = 金額 ÷ 對應的天數

初始預估

Preliminary forecast

前一個月 19～20 號產出的下個月預估。上個月 GMV 以當月的校正後全月預估代入，下個月 1 號會被正式預估取代。

正式預估

Official forecast

每月 1 號用上個月的完整資料產出的全月預估。產出後鎖定，是儀表板「全月預估」卡片顯示的數字。

MTD 實際

Month-to-date actual

當月 1 日到資料截止日的實際 GMV 加總。

校正係數

MTD actual ÷ forecast

大於 1 代表目前跑得比預估快，小於 1 代表比預估慢。會用來校正剩餘天數的預估。

校正係數 = MTD 實際 ÷ 同期間每日預估加總

校正後全月預估

Corrected full-month

已經發生的天數用實際值，尚未發生的天數用預估值乘上校正係數。All biz type 為三個 Biz Type 校正值相加。

校正後全月預估 = MTD 實際 + 剩餘天數每日預估加總 × 校正係數

最後校正預估

Last corrected forecast

一個月份最後一次執行時的校正後全月預估，通常是 19～20 號那次。月份結束後保留下來，用來比較月中校正是否比正式預估更準。

預估誤差

Forecast error

過去月份的實際與預估的差距。正值代表實際高於預估。

預估誤差 = (實際 − 預估) ÷ 預估

相關係數 r

Pearson correlation

衡量因子值（x）與實際 GMV（y）的波動方向是否一致，範圍 −1 到 1。分子看兩者是否同漲同跌，分母做標準化。|r| < 0.44 的因子會被排除。

r = Σ(x − x̄)(y − ȳ) ÷ √[ Σ(x − x̄)² × Σ(y − ȳ)² ]

MAPE

Mean Absolute Percentage Error

平均絕對百分比誤差，數字越小越準。例如 MAPE 10% 代表預測平均偏離實際約一成。

MAPE = 平均( |實際 − 預測| ÷ 實際 ) × 100%

預測區間

± error range

以模型在最近 3 個完整月份的平均誤差率（MAPE）當作誤差範圍，表示實際值大致會落在的區間。

預測區間 = 預測值 × (1 ± MAPE)

06後續優化方向

模型自動化執行

目前
需要透過手動更新資料，才能輸出預測結果。
後續
研究自動化機制，讓模型能自動讀取資料集、自動訓練與預測，並自動更新儀表板中的預測結果。

加入日期特徵

目前
以各 Day Type 的業績占比回推每日的 GMV 預估。
後續
加入日期特徵，讓模型能根據 Day Type 與日期做每日的業績預估。

新增每年的預估

目前
可以看到 by daily 和 by month 的預估。
後續
新增 by year 的預估。
